Method and source

Flow. (shares outstanding today − yesterday) × NAV per share. Creations and redemptions are the only thing that moves shares outstanding, so this is the flow, from the issuer's own numbers. Zero days are true zeros — no basket activity — not missing data.

Growth %. Period flow over net assets at the period's start: an organic growth rate, insulated from ZEC's price moves. AUM change ≠ flow — most of ZCSH's AUM growth so far is mark-to-market.

Pipeline. A GitHub Action fetches Grayscale's daily product-performance file each weekday evening after NAV posts, recomputes the series and commits it here. Data shown is exactly that file, no third parties in the chain. Timestamp top right; the Refresh button re-reads the latest committed data.

Scope. ZCSH is currently the only listed US spot ZEC ETF. Bitwise has one pending — when it lists, this page will need a second column and a revised total. Pre-conversion trust history (back to 2021) is in the data file but excluded here: the trust had no redemption mechanism, so ETF-style daily flow doesn't exist for that era.
